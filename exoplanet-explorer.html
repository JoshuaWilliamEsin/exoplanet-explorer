How to run this demo

This page runs entirely online: it queries NASA's API live through the hosted companion server, no setup needed. Want to run it offline on your own machine instead? NASA's API blocks cross-origin browser requests, so the page fetches through the tiny companion server (server.py). Put exoplanet-explorer.html and server.py in one folder and follow the steps.

  1. Open PowerShell in the folder that holds both files.

  2. Start the companion server:

    PowerShell
    PS>py server.py

  3. Open the demo in your browser:

    browser
    http://localhost:8000/exoplanet-explorer.html

No dependencies beyond Python, no API key anywhere.
